# Bodycam Duel — мобильная сетевая дуэль 1v1 (Godot 4 + GDScript)

Мобильная 3D-игра для Android с bodycam-эффектом и Listen Server: один игрок
создаёт комнату, второй подключается по локальному IP. Бот удалён.

## Что внутри

- Listen Server через встроенный `ENetMultiplayerPeer`, максимум 2 игрока.
- Каждая копия `Player` владеется своим peer: движение, прицеливание, здоровье
  и выбранное оружие синхронизируются RPC.
- Новые ассеты из `models.zip`: rigged `a_lowpoly.glb` с текстурами,
  `PBR_Pistol.glb`, `M4A1.glb` и PBR-текстуры M4A1.
- Процедурные runtime-анимации рига: ходьба, прицеливание, отдача и смерть.
- Переключение оружия в матче: мобильная кнопка **WEAPON** или клавиша Q.
- Меню с GLB-персонажем, M4A1 и лёгким 3D-дымом.
- Compatibility renderer, 30 FPS watchdog, landscape и `armeabi-v7a` для Realme C30s.

## Как играть по сети

1. На первом устройстве нажать **CREATE GAME**.
2. Второе устройство должно быть в той же сети Wi‑Fi; ввести локальный IP первого
   устройства и нажать **JOIN GAME**. Порт — `8910` UDP.
3. После подключения оба игрока появляются на разных сторонах карты.

## Управление

| Действие | Мобильное | Клавиатура/мышь |
|---|---|---|
| Движение | левый виртуальный джойстик | W / A / S / D |
| Обзор | свайп по правой части экрана | мышь |
| Выстрел | **FIRE** | ЛКМ |
| Перезарядка | **RELOAD** | R |
| Присесть | **CROUCH** | C |
| Смена оружия | **WEAPON** | Q |
| Рестарт | **RESTART** | Enter |

## APK через GitHub Actions

`.github/workflows/android.yml` не изменён. Запусти workflow **Android Build**
через `workflow_dispatch` и скачай артефакт `bodycam-duel-debug-apk`.

Проверки перед отправкой: `python3 tools/lint_types.py` и
`python3 tools/validate.py`. Локальная машина агента не содержит Godot, поэтому
финальную проверку импорта и APK выполняет GitHub Actions.
